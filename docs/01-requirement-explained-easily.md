# Requirement explained in easy language

## The business problem

Clinical labs currently spend a lot of money and time sending MRD samples to outside companies for analysis. Those outside labs can be slow, expensive, and hard to coordinate. Allovista wants to change that by bringing the analysis in-house.

In plain English:

- Labs want to do the testing themselves
- They want it to be faster
- They want it to cost less
- They want data to be available the same day
- They want a system that can support doctors with clear reports

## What the platform must do

The platform should act like a clinical bioinformatics engine. It takes raw lab data, processes it automatically, checks quality, runs analysis, and presents a report.

The system should handle multiple data types:

- amplicon sequencing
- RNA sequencing
- mass spectrometry

It should then combine these analyses into a clinical report that tells physicians whether disease is present, how much remains, and whether the result is consistent across methods.

## Why this matters

For MRD testing, time matters. Doctors want to know if a patient is responding to treatment. A platform that can do this quickly and accurately can improve patient care and reduce cost.

## What the role is really asking for

They are hiring a technical person who can do two things:

1. Build the bioinformatics pipelines that run the analysis
2. Build the clinical reporting interface that doctors and lab staff can use

That means the person must be comfortable with both technical biology workflows and application development.

## Simplified interpretation of the job

They are looking for a hybrid engineer who can:

- understand sequencing and lab workflows
- build AWS-based automation
- create data processing pipelines
- produce clinical-grade analytics and reports
- work closely with the founder and early lab customers

## Summary

The company is not asking for a generic SaaS app. They want a specialized clinical platform for molecular residual disease testing, built to be useful in real labs and strong enough for early validation.
